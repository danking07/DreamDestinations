## DreamDestinations website

## Project Description and problem solved

Planning a trip can be overwhelming, especially when you're unsure which destinations fit your budget. DreamDestinations solves this by organizing travel destinations into clear budget categories, allowing users to explore options and make bookings directly on the platform.

In this web application it has a list of destinations corresponding with the budget either low mid or high budget.



##  Live Pages

index.html— Homepage with hero section and booking count
destinations.html — Browse destinations filtered by budget
booking.html — Fill in and submit your booking reservation



## How it works
1. The user clicks the start exploring button in the home page.
2. Then the user selects their budget either Low Mid and High
3. The web application brings out a list of destinations based on the budget.
4.The user selects their prefered destination and clicks the book now.
5.The web application takes the user to the booking form where the user inputs their details and their destination and the booking is saved.

## BDD Behavior Driven Development

1 User submits form without inputing anything in it
The web applications sends an error message to the user telling them to input the fields

2 User clicks the budget buttons
The user clicks one of the budget buttons either low mid or high and the web application displays the destinations based on button clicked.

3 User individually submits form without filling one of the fields
When the user submits without filling one of the field the respective fields inputs an error message based on the field

4 Saved Bookings
When the user submits the form the web application saves the users booked information.
